# Guardes

Aquí hi ha l'eina del cervell, `cervell.js`, copiada de TeamTowers
(`SOS/tools/cervell.js`) sense tocar-la: la porta al dia `--actualitza`. El que
canvia d'un projecte a un altre va a `../cervell.json`, no al codi.

Les guardes pròpies d'aquesta web són a `../tools/` (`check.js` i
`prova-firma.js`). Una guarda nova es prova **trencant a posta** el que ha de
trobar. Llegir-la i veure que sembla correcta no compta.
